# Independent review of the overnight drafts (2026-09-26)

Reviewer: a separate assistant instance (general-purpose subagent), asked to find problems before the author signs. It ran self-tests and toy seeds only, checked quoted prior numbers only, and edited nothing. Its findings are summarized below as delivered (condensed wording), followed by the response table. The response column records what was changed tonight, before any signature and before any registered run.

## Findings (as reported, most severe first)

1. **BLOCKER, hash lock defeats itself.** §16 asks for the file's own SHA-256 inside the file, the OSF id is later copied into §16, and Appendix L2 is appended to the same file, so the local protocol never matches the registered bytes; the guard only checks the string "SIGNED"; outputs record the post-L2 hash. Fix: freeze L1 bytes; record the hash outside; put sign-off details, OSF id, and L2 in a separate addendum with its own sign-off; guard compares the L1 hash with a pinned value; provenance records both hashes.
2. **BLOCKER, G2′ not like-with-like.** (a) GSV gets P10 re-sequencing free while P7-matched end points keep their random order; (b) P7-matched de-duplicates its 20 verified waves but GSV does not, and identical (source, destination, ready) sequences have identical values under all evaluators (toy check: the M2 top 20 held 9 to 15 distinct sequences in 7 of 15 settings; P11 produced as few as 32 distinct sequences of 200). Fix: give P7-matched the P10 operator; de-duplicate both shortlists by sequence signature, also in the G3 grid; report distinct counts.
3. **MAJOR, verification model is the scoring model.** Deterministic DES-M2 both selects and scores; no winner's-curse or misspecification check. Fix: an independent execution evaluation of released waves (DES-M2 with lognormal phase noise σ = 0.1, 0.2, common random numbers across arms; and/or `b5_compat`), or scope all wording to "under the verification model".
4. **MAJOR, G2 and G5(b) near-certain.** G2 compares 6,200 M2 + 20 DES evaluations with a zero-evaluation P8; add P8-verify(20). G5(b) compares a prefix-aware GSV chain with blind random P0 chains; base it on retention of the single-wave gain or on the P5 chains.
5. **MAJOR, warm start ignores the §5.5 contingency** (chains always screen by M2); G5(a) samples all 6,200 candidates although §9 and the 95% rationale refer to random candidates.
6. **MAJOR, story scenarios not exhaustive**; "otherwise the story is B" contradicts B's condition; no wording rule for C2 if G4 or G8 is lower, nor for C3's constructor claim if the ablation shows P11 adds nothing.
7. **MAJOR (uncertain; depends on the estimand), S1-1 motivation.** Under the finite-class estimand the row bootstrap is standard and the clustered one is conservative; it is a correction only for a superpopulation estimand, which is not stated. Report the row-level range over 10 seeds (informally 56 to 58/72) next to 57/72.
8. **MINOR, factual errors.** "8 runs" called the Phase 5 definition of P7 (Phase 5 used 200 runs per cell); Supp-1 random arm is 12/12 positive and 10/12 above 1%, not 11/12; "104 of 600" is not reproducible from the shipped self-test (73 of 400 DES-M2 cases).
9. **MINOR, gate wording and definitions.** G1 upper wording still compares DES with closed form; G1 cell value undefined in text; G3's 2% is about 1 s at n = 8; G8 says "screening" but DL is at k = 1; P10g described as "without readiness" although it orders blocks by ready time.
10. **MINOR, code versus protocol.** R-verify key "6200" holds k = 3,000; ablations silently skip k; tie counts only at the M2 minimum and DL; GSV and R-verify lack M2 values; P7-matched ties by discovery order; an empty P5 corner crashes `run_chain`.
11. **MINOR, statistics.** Holm bound not monotone; a comparison silently dropped when all values are identical; Wilcoxon sidedness and zero handling unspecified; bootstrap only for GSV20 with seeds 20260926 + i; per-size sensitivity, k* relative to the R optimum, and G2 budgets not implemented; P11 percentile interpolation unspecified.
12. **MINOR, code freeze and contingencies.** No shipped randomized test for G0 item 3; B-5 reproduction and P9 equality tests SKIP and pass on import failure; `P11_WEIGHTS` and `CASE_TIMING` are code edits after tuning (L2 hash differs from the tuning run's hash); warmstart and runtime do not check the weights; the §14 subset contingency is not implemented and its stream is unspecified; the runtime projection would run on a test configuration; §11 data-cleaning rules not registered.
13. **MINOR, Study 1 documents.** S1-7 rule wording; S1-6's 0.80 threshold sits just above the informal maximum 0.78; primary dataset rule differs between items; S1-2's primary favourable corner fixed only in the Chinese summary; "Theorem 2" naming clashes with the story contract; S1C crossed versus one-at-a-time; S1-12 writes into tier2 outputs and records the Phase 6 hash instead of S1B's.
14. **MINOR, cross-document mismatches.** STORY_CONTRACT cites S2-2 to S2-6, which the protocol does not define; D-D1 points to a non-existent file; the execution log promises a helper report that is not there; README_OSF omits STORY_CONTRACT; TERMINOLOGY leaves P10(R) out of G; no rule for Study 2 results that contradict the direction of a Study 1 result.

Checked and found correct by the reviewer: all self-tests; guard stops; timing pass-through; seeds and streams; index mapping; P5, P8, P9, P2; P10, P10g, P11 versus the protocol; budgeted local search; the corrected DES boarding rule (24 versus 43 by hand); GSV ranking, k*, DL tie mean, ordering counts, ANOVA estimators, gate thresholds, Holm decisions; all other quoted prior numbers.
