# 论文主线:从动机到贡献

> 怎么读:本文档按"为什么做(动机)→ 怎么做(两个工具)→ 跑出什么(效果)→ 贡献是什么"
> 一条主线展开。每一步都尽量给具体数字和一句大白话。看完你应该能用三分钟把整篇讲清楚。

---

## 0. 一句话主线

多层 AMR 仓库里**共享电梯是瓶颈**;"把哪些订单拼成一波"(战术决策)会影响电梯负担,
但**它到底值多少、其中又有多少被电梯运力卡死**,以前没人量得清。
我们**固定操作层、只研究战术层**,在同一个三维表示上提出**两个工具**:
一个**诊断**价值(能省多少、其中多少可回收),一个在模型不确定下**处方**该选哪类波次;
在 106,800 次仿真上验证,得到"**容量侧主导**"这个可操作的管理诊断,
外加**一条几乎总好使、带保底的闭式选择规则**。

---

## 1. 动机:问题在哪,缺口在哪

**场景**:多层楼、一支灵活 AMR 机队、若干共享货梯。电梯是瓶颈。

**缺口**:波次构成、多层部署、灵活机队、共享电梯运力这四个要素,以前大多被**分开研究**,
各自靠"限制设定"绕开它们之间的耦合(固定波次内容、或只看单器件、单楼层)。
但在一般设定下,**波次构成在机队调度行动之前,就已经定死了电梯的行程分布**
(要跑多少趟、朝哪些方向、多集中),所以战术层和操作层**分不开**。

**两阶段**:战术阶段(拼波次)+ 操作阶段(AMR 经电梯把订单送达)。
**本文固定操作阶段,只研究战术阶段。**(操作层用 AI agent 求最优是另一篇 Pillar-2 的事。)

**两个驱动观察**(它们分别催生了两个工具):
1. **波次结构的价值随场景变,而且分两块**:一块被电梯运力卡死、任何放行策略都拿不到;
   另一块更好的放行策略能拿回来。两块孰大孰小随场景而变 → **需要一把会"量"这两块的尺子**(工具 1)。
2. **运营者不知道真实电梯模型**,但这些模型在每个波次上**一致排序**,最慢的永远是同一个 →
   **可以拿这个"最慢模型"当基准,做稳健选择,不必识别真模型**(工具 2)。

---

## 2. 工具:一个表示 + 两个工具

### 2.0 共同地基:三维表示 Φ = (C, I, T)

把每个波次用三个量概括:**C 垂直分散度**(高 = 活动摊在很多楼层)、**I 方向不平衡**、
**T 时间聚集**。再把候选波次按 (C, I) 切成 **2×2 四个角**。
一个"角"= 一类波次结构(wave-structure)。两个工具都在这上面操作。

### 2.1 工具 1:Bound-and-Gap 分解(诊断性),回答"值不值、能省多少"

**做什么**:把"波次结构的价值"GAP 拆成两块:
- **H_up**(结构性天花板):被电梯运力卡死、**任何放行策略都拿不到**的部分;
- **M_Φ**(可回收余量):**更好的放行策略能拿回**的部分。

**正式结果(三个,全部无条件成立)**:
- **命题 1(分解)**:对**任意 cell、任意分区**,`GAP = H_up + M_Φ`。这是个**恒等式**,按定义就成立。
- **定理 1(SPO 等价)**:`M_Φ` **恰好等于**一个分区常数预测器的 SPO 损失(predict-then-optimize 决策损失)
  → 因此**能直接交给现成的 SPO / 决策聚焦方法去回收**,不用发明新方法。
- **推论 1(细化单调)**:分区越细,`H_up` 不会变小 → 告诉你"细化分区"是另一根可拉的杆。

**怎么读(诊断表)**:`H_up` 大 / `M_Φ` 小 → 容量主导,别折腾构成,去拉运力或细化分区;
`M_Φ` 大 → 构成是大杠杆,值得做。

### 2.2 工具 2:Model-Dominance Hedge Rule(处方性),回答"选哪类、怎么稳"

**做什么**:拿**"最慢的电梯模型 M2"(真实共占批处理)当唯一基准**,量每一类波次结构,
**选在它之下工期最短的那一类**放行。不用辨识真模型、不用解任何优化、**一行闭式规则**。
为什么拿最慢的当基准:在最坏情形下都最好,则不管真模型是哪个都不吃亏 → **稳健**。

**正式结果(三个)**:
- **定理 2(minimax 坍缩 = DRO)**:**在链支配下**,"对模型取 minimax 的选角"坍缩成
  "M2 下最优角",并且**等于 Wasserstein 分布鲁棒优化(DRO)的最优解**。
- **命题 2(条件链支配)**:链支配(`M1 ≤ M2` 逐波次)在 **(a) 同派单顺序 + (b) 无批处理插队** 下成立。
  **它的作用是给定理 2 提供前提**(不是额外限制,而是"证明定理 2 需要的那个条件成立")。
- **推论 2(单边 ε 界)**:当前提只近似成立时(M3 噪声、或那 0.8% 插队波次),**最坏损失 ≤ `U_c(ε)`**。

### 2.3 两个工具怎么一起用(分工 + 顺序)

它们针对**同一个决策**(从哪类波次结构放行),但回答两个不同问题:
- **工具 1 = 闸门**:先问"这儿**值不值得**动手、能省多少"。
- **工具 2 = 动作**:若值得,再问"那**选哪类**才稳、最坏差多少"。

```
拿到一个仓库 (F, |A|, E, 需求)
        │
        ▼
[1] 在候选波次上算 Φ=(C,I,T),按 (C,I) 切 2×2 四角
        │
        ▼
[2] 工具 1:算 GAP = H_up + M_Φ
        │
   ┌────┴────────────────────────┐
   ▼                             ▼
 H_up 大 / M_Φ 小              M_Φ 不可忽略
 容量主导:别折腾构成,         构成值得做:
 去拉运力或细化分区              ▼
                          [3] 工具 2:用 M2 当基准选最优角
                                ▼
                          [4] 报最坏界 U_c,带保底地放行
```

## 3. 一个具体例子:配置 7(真实数字)

仓库:**5 层楼、5 台 AMR、2 部货梯、聚集型需求**。数字直接读自 Phase-5 产物。

| 量 | 值 |
|---|---|
| `H_up`(结构性天花板) | **0.157**(占基准工期 15.7%) |
| `M_Φ`(可回收余量) | **0.021**(占 2.1%) |
| `GAP = H_up + M_Φ` | **0.178**,95% CI [0.099, 0.285](排除 0,价值真实存在) |
| Hedge 选出的角 `c*` | **LC_HI**(= DRO 最优角) |
| 逐波次支配 `M2 ≥ M1` | 各角 **0.99–1.00** |
| 最坏界 `U_c(0.05)` | **3.4% 工期**(9.5 个时间单位 / 基准 283) |

**四步操作(运营者视角)**:
1. **算 Φ**:在候选波次上算 (C,I,T),切四角。
2. **读分解(工具 1)**:GAP=0.178 真实存在,但 `H_up` 占 **88%**、`M_Φ` 只占 **12%**。
   读法:**构成已经接近这个分区下的最好,剩下的工期是结构性的。别为了 2.1% 去上一个特征工程项目,真要快就加运力。**
3. **选角(工具 2)**:若仍要放行,Hedge 规则给 **LC_HI**;支配在 99–100% 成立,minimax 坍缩成这一闭式,**不用辨识电梯模型**。
4. **报保底(推论 2)**:就算模型判断错了,跟随 M2 角**最多损失 3.4%**,而且这个数运营者能用自己的数据算出来。

**一句话**:工具 1 说"这儿构成是小杠杆(12%),容量才是大杠杆";工具 2 说"真要做,放 LC_HI,稳健、带 3.4% 保底"。

## 4. 达到的效果:数据说明了什么

注意:**这些数字不是"我们把工期降了多少",而是"证明这两个工具可信、能用"。**

| 数据 | 含义 | 价值 |
|---|---|---|
| 逐波次支配 **99.2%**(最差 96.0%),`c∈{2,3,4,5}` 都成立 | 工具 2 的前提几乎总满足 | 这条闭式规则**实际几乎总好使**,不是纸上谈兵 |
| Hedge 角 = Wasserstein-DRO 最优(**每个配置**) | 便宜口诀 = 昂贵难解法的答案 | **稳健性白送** |
| 两个恒等关系 **72/72 精确** | 分解是精确等式,不是近似 | **一本靠得住的账** |
| `H_up` ≈ **72%** of 平均 GAP | 平均看,容量侧主导 | **核心管理诊断:杠杆在哪一侧** |
| 分辨门槛 **79%**(57/72,部分通过);判别 **AUC 0.92**、分辨/未分辨中位 GAP **0.064 vs 0.017**(3.8 倍) | 能准确分辨"哪儿构成有用";没分辨出的恰是价值近 0 的 | **即便容量主导,工具靠"会挑重点"立足**;79% 部分通过≠失败 |
| 最坏界 `U_c` ≈ **3.4%** | Hedge 规则稳健性被量化且小 | **下行有界,可自算** |
| (Block B)Φ 角规则 P5 胜随机基线 / 实务启发式各 **83%**,胜 SPO-Tree 67% | Φ 角选择确实优于常见做法 | 工具 1 的诊断与实际选择一致 |

**价值怎么从数据体现**:这篇交付的是一套**精确(72/72)、有判别力(AUC 0.92)、被诚实刻画(79% 部分通过、72% 容量)的诊断工具**,
加上**一条前提几乎总成立(99.2%)、与 DRO 最优一致、最坏只差 3.4% 的闭式稳健规则**。
**数据验证的是"方法成立",不是"工期下降",这正契合方法论贡献的定位。**

## 5. 贡献:C1 / C2 / C3

- **C1 问题形式化**:把"垂直资源约束下的波次放行协调"形式化为两阶段调度,
  以往多以简化设定回避波次与电梯的耦合,本文显式纳入模型。
- **C2 方法**:在 Φ 上提出**两个工具**(共 6 个正式结果,见第 6 节)。
  工具 1 把价值的可回收部分**接入** predict-then-optimize 文献(可复用现成方法);
  工具 2 把"模型不确定下的选角"在链支配下坍缩成**闭式 = Wasserstein-DRO 最优**。
- **C3 经验洞见**:在出版规模上得到"**容量侧主导**"的管理诊断 + 工具的判别力;
  如实报告两个工具结论不同(Hedge 全过门槛,Bound-and-Gap 部分通过)。

**两层好处、面向两种人(以工具 1 为例)**:
- **可用**(给想解决问题的人):问题正好套进成熟方法库,拿现成算法即可("锁配上了量产钥匙")。
- **可被借鉴**(给想接着研究的人):(a) 给 predict-then-optimize 一个**新视角**
  (可回收余量 = 分区预测器的损失);(b) 开了一块**新应用域**(多层 AMR 波次释放)。

## 6. 6 个正式结果速查地图

| 编号 | 属于 | 说什么 | 角色 | 有条件吗 |
|---|---|---|---|---|
| **命题 1** | 工具 1 | `GAP = H_up + M_Φ` 成立 | 结果(送你分解) | **无条件**(任意 cell、任意分区) |
| **定理 1** | 工具 1 | `M_Φ` = SPO 损失 | 结果 | 无条件 |
| **推论 1** | 工具 1 | 分区细化时 `H_up` 不减 | 结果 | 无条件 |
| **定理 2** | 工具 2 | minimax 选角坍缩成闭式 = DRO 最优 | 结果 | **要前提:链支配** |
| **命题 2** | 工具 2 | 链支配在(a)同派单顺序+(b)无插队下成立 | **给定理 2 供前提的"保证书"** | 它本身就是"给条件" |
| **推论 2** | 工具 2 | 前提只近似成立时最坏损失 ≤ `U_c(ε)` | 兜底 | 处理"前提不完全满足" |

**关键**:"命题"不都等于"前提"。**命题 1 是结果(无条件白送你分解)**;
**命题 2 是给定理 2 提供前提的保证书**。所以:
- **工具 1 无条件成立**(纯数学,放哪都对);
- **工具 2 只有一个条件(链支配),而命题 2 + 99.2% 的数据把这个条件兜住了**。

## 7. 诚实的边界(答辩主动说,反而是加分)

- **什么泛化,什么不泛化**:**工具本身泛化**,工具 1 是恒等式 + 定理(无条件),
  工具 2 是定理 + 命题 2 给的可检验条件;换个仓库重跑即可。
  **但具体数字(72%、79%)不泛化**,它们是本网格的测量值。
- **容量主导是"发现",不是"失败"**:它纠正了"构成是大杠杆"的常见预设,
  并指挥运营者把劲使到对的杆上(运力 / 细化分区)。工具的价值正是"会告诉你该往哪使劲"。
- **工具 2 的量级随场景变**:容量主导处它省得少(配置 7 只够 2.1%),M_Φ 大处它省得多;
  但它"**不用辨识模型、闭式、带保底**"的价值与量级无关,且这是给 DRO 文献的方法论贡献。
- **Bound-and-Gap 的 D1-d 报成 PARTIAL(79%)**:没分辨出的集中在价值近 0 处
  (13/15 的 GAP 比自己的置信区间半宽还小),所以"分不清也无所谓";如实报告、不硬说全过。
